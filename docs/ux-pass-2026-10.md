# Phone UX pass (October 2026)

## Purpose

Four testers played the guest NBA practice draft on a 390px phone and on a
desktop and called it clunky: too much competing for the first screen, a clock
that kept running while they were still choosing, and auto-picks that arrived
with no explanation. The brief was split into sections A to G and shipped in
that order. This file records what each section changed and why, so the next
pass starts from what was decided rather than from the screenshots.

Every change here is **shared UI**: it applies to NBA and NFL alike, and to
practice, ranked and friend drafts unless a line says otherwise.

## A. Draft board

| Change | Where | Notes |
|---|---|---|
| "Pick 3 of 10" replaces "Round 3" | `pickCountLabel()` in `js/main.js` | Counted from the roster, not the round: a round with no legal player costs no pick, so the two drift apart. Online drafts use it too. |
| Clock pauses while a dialog is open | `startPickTimer(..., { pausable })`, `isModalOpen()` in `js/shell.js` | **Local drafts only.** Online the server holds the clock, so pausing the client's copy would only misreport the time left. |
| 60-second clock for a guest's first draft | `FIRST_DRAFT_PICK_TIMER_SECONDS`, `pickTimerSeconds()` | "First" means no finished guest game stored on this device (`pendingGuestGames()`). |
| 5-second warning, then a toast naming the auto-pick | `#pick-warning`, `announceAutoPick()`, `js/ui/toast.js` | A forfeit toasts too, with its own wording. |
| Forfeit moved to the banner's top row, two taps to fire | `#btn-forfeit-pick`, `.forfeit-btn` | The first tap arms it for 3 seconds and changes its label. |
| Season and slot in one sheet | `openSeasonPicker()` | A season that still leaves a real position choice carries the slot buttons on its own row; one tap picks both. Single-slot and bench-only picks still place themselves. |
| Wrong-guess note is short and waits for typing to pause | `renderPool(..., { settled })`, `SEARCH_SETTLE_MS` | "Not on the 2000s Grizzlies. Try again." Matches still show on every keystroke; only a miss waits. |
| "Stuck? Show some names" | `renderSuggestions()` in `js/ui/draft-board.js`, `renderPoolSuggestions()` | **Practice only, on request, once per pick.** Five players who fit an open slot, most games first (recognisable, not best - a rating sort would be an answer key). Ranked and friend drafts never show it. |
| Calm one-line hint | `applyModeToDraftUI()`, `.knowledge-hint` | Says the bot (or opponent) picks too, which is the one rule a first draft cannot guess. |
| Round reveal in sentence case | `.turn-banner.turn-reveal` | "Bot picked Terry Rozier (Bench)". |
| No more "Locked in" on a random opponent row | `renderRosterPanel` `pendingSlots` | A hidden pick's slot was itself a leak, and read as a bug. The panel heading says "picked ✓" instead. |
| Opponent's roster folds into a drawer on a phone | `renderRosterPanel(..., { collapsible })` | Below 860px only; a desktop keeps the column. The folded state survives re-renders. |
| Two-line roster rows, every sport | `renderRosterPanel` | Name, then team and year. Each line truncates on its own. |
| Slot strip wraps instead of scrolling sideways | `.position-selector` (phone) | Ticks rather than names in a cell: the names are one panel down at full width. |

### Known limitations

- Online drafts get the drawer, the pick counter, the two-tap forfeit, the
  warning and the toast, but not the paused clock or suggestions - both by
  design (see above).
- "First draft" is per device and per browser profile, like the rest of guest
  state.

## B. Post-draft steps (rotation, matchups, game plan)

| Change | Where | Notes |
|---|---|---|
| "Step 1 of 3" in the banner | `beginSetup()`, `enterSetupStep()` in `js/main.js` | Counted from what the sport declares: three for basketball, two (offense, defense) for football. |
| Draft grade and rosters fold behind one button | `#btn-view-rosters`, `.setup-live` / `.show-rosters` | The grade folds at every width; the rosters fold below 860px only, since a desktop has columns for them. |
| No clock on the steps after a local draft | `renderDraftComplete()` | At every difficulty. Online keeps its clocks (a real opponent is waiting), and every timed step's hint now says what happens when the clock runs out. |
| Rotation steppers, "Use default", sticky actions | `renderRotationPicker()` in `js/ui/strategy.js`, `.phase-actions` | One tap is one minute. The minutes-left count sits with Confirm, and on a phone that bar is sticky. The slider track now keeps the position's full range (it used to shrink to the cap, which put every thumb at the far end once the budget was spent). |
| Matchups read as a sentence | `renderMatchupPicker()` | "Kobe Bryant defends [their SG]"; the dropdown is labelled for screen readers; the swap rule is in the hint. |
| No pre-selected game plan | `startTacticPhase()` | The button waits for a choice. If a clock runs out with nothing chosen, the first plan on offer is used, and the hint says so up front. Choosing a card no longer restarts football's clock. |
| Plain-language plans | NBA blurbs in `js/sports/nba/tactics.js` (vendored copy updated); football's trade chips render as "Better at" / "Worse at" | Display only. The sizes are still on each chip's tooltip. |
| Two-line names on rotation and matchup rows | `seasonLabel()` moved to `js/ui/entry-name.js` | |

### Not done from section B

- B4 asked for the grade to be hidden until after the game, or replaced by a
  plain strength bar. It is folded behind a button instead; moving it to the
  results screen is a larger change to the results layout and belongs with
  section C's restructure if wanted. The unexplained numbers on the card
  ("Starters 84 / Bench 81 / Reb 62") are unchanged.

## C. Results and live game

| Change | Where | Notes |
|---|---|---|
| Result first on a phone | `#screen-game` order rules (section C block in `css/style.css`) | Score, verdict, MVP, Share / Play Again, then the account offer, then the recap and details. Desktop order is unchanged. |
| Box score, shot chart and "Why you lost" as tabs on a phone | `renderResultTabs()` in `js/main.js` | Only panels that are showing get a tab (football's results have no shot chart). Arrow keys move between tabs. Desktop shows all three. |
| Compact phone box score with "More stats" | `boxPhoneColumns` on the basketball sport module, `markPhoneColumns()` in `js/ui/game.js` | Player, MIN, PTS, REB, AST, FG, 3PT until "More stats" is tapped. Optional per sport; football declares none and is unchanged. |
| Smaller live court on a phone | `.basketball-court .bc-court` | Same shape (188:100), about 18% of the screen height. |
| Lead changes said once, in sentence case | `createFeedVoice()` in `js/sports/nba/playback.js`, the lead-change block in `js/main.js` | "Bot takes the lead" and "Bot TAKE THE LEAD" used to land as two cards. |
| Play Again starts a new draft for a guest | the `btnPlayAgain` handler | Same sport, straight into the draft. A signed-in player still lands on the setup screen with everything pre-selected, by design. |

### Not done from section C

- Football's result screen is still long on a phone (three box-score tables a
  side). It gets the new order but no compact columns yet; football would
  need to declare which columns each of its groups keeps.

## D. First-time guidance

| Change | Where | Notes |
|---|---|---|
| "How a round works", once per device | `js/ui/round-intro.js`, `#round-intro` | Three steps in a card above the search box on a first draft, local drafts only. A card rather than a dialog, so nothing waits on dismissing it; it goes on "Got it" or with the first pick. It does not pause the clock - a guest's first draft already has 60 seconds. |
| The era chip explains itself | `renderDraftEra()` | Its tooltip carries the era's own blurb; the intro says "a random team from any era". |
| Practice cards lead the homepage | `#btn-quickplay-friends` is secondary | The friends card was already below the sport cards; its orange button outweighed them. |
| Sport cards enable without waiting for the auth library | the boot block at the end of `js/main.js` | With no stored session (the same key `boot-session-hint.js` reads) the page enters guest mode straight away instead of after supabase-js downloads from its CDN. The session check still runs, and no longer re-enters guest mode over a game already started. |

## E. Phone technical fixes

| Change | Notes |
|---|---|
| Inputs at 16px or more on a phone | A floor with `!important`, so a more specific rule cannot undercut it and trigger iOS zoom. `#pool-search` was already 16px at phone width in this build. |
| 44px targets | `#btn-quickplay-signin` and the Privacy / Terms links. |
| 14px helper text on a phone | `.hint-text`, `.legal-note`, `.quickplay-status`. |
| `dvh` | `body` and the modal already used `dvh` with a `vh` fallback; the new sticky bars and the toast use `env(safe-area-inset-bottom)`. |
| Desktop's empty middle column | Says "Matches appear here as you type." and the hint is larger. |

## F. Dropped to the landing mid-draft (desktop, seen once)

**Not reproduced.** A guest idled through picks 5 to 7 for 160 seconds at
1440px in Chromium: no navigation, no errors, still on the draft. No code path
sends a guest to the landing without a click (sign-out, the logo, the nav, the
"can't play" buttons).

The likeliest cause is the page itself going away: a reload, a trackpad
back-swipe, or the browser discarding an idle tab. A local draft keeps no state
across a reload, so that lands on the homepage with the game gone - exactly the
report. Two changes:

- A draft or a game still playing now asks before the page unloads
  (`beforeunload`). It cannot stop a browser discarding a tab.
- The boot's session check can no longer show the homepage over a game in
  progress (see D).

Saving an in-progress draft so a reload can resume it is the real fix for tab
discards, and is not done.
